# Сюжетные катсцены Pythonlancer

Исходник сцены — класс `Scene` в `story/cutscenes/story_scenes/`.
Позиции живут в дампе `Assets/SCENES/DUMPS/<DUMP_FILE>.json`.
Блендер — только станок, с которого этот дамп снимается.
Сценарий миссии не подгоняется под сцену. `VOICE_LINES` остаются как есть.
Если индекс или актёр реплики не совпал, `facial()` падает. Это нормально:
файл сцены — заготовка, её обтёсывают, а не чинят сценарий.

Образец ручной постановки — `story/cutscenes/story_scenes/m09_yokohama.py`
и `m09_reward.py`. `Autoplay` для этих сцен не используется: жест и камера
задаются явно, а не очередью `anim_sequence`.

## Как течёт время

Часы сцены — `MAIN`. Их двигают только `append_time` и `facial()`.

`facial(index)` берёт длительность wav и прибавляет её плюс `extra_delay`
(по умолчанию 0.3). Следующая реплика начинается, когда кончилась предыдущая,
а не по секундам из старого `.thn`.

Действие до реплики пишется до `facial()` и не сдвигает часы.
Действие внутри реплики — тот же вызов, но `time_delay` от текущего
момента группы, то есть от начала реплики. `facial()` после этого
всё равно сдвигает часы на длину файла.

Подход, уход, пауза между блоками — отдельные биты через `append_time`.
Они не привязаны к wav.

Пока у реплики нет lip-meta, ставить `auto_lip=True`.
Когда мета записана, как в миссии 9, `auto_lip` убирается и остаётся `facial(index)`.

## Группировать delay

Если несколько действий идут одно за другим от одной точки, не писать
каждому свой абсолютный delay.

Плохо:

```python
self._m(trent, anim_a, 20, 3)
self._m(trent, anim_b, 21, 2)
self._m(barman, anim_c, 22, 4)
```

Так:

```python
t = 20
self._m(trent, anim_a, t, 3)
t += 1
self._m(trent, anim_b, t, 2)
t += 1
self._m(barman, anim_c, t, 4)
```

`t` — курсор внутри бита. База пишется один раз, дальше только приращение.
Одинаковый момент — один и тот же `t`, без `t += 0`.
Дырка в несколько секунд — один `t +=`, а не новая абсолютная цифра.

`append_time` для этого не годится, если следом идёт `facial()` этой же реплики:
`append_time` сдвинет начало реплики. Внутри реплики курсор только в `time_delay`.
`append_time` — для бита до первой реплики и хвоста после последней.

Интро в `m01.py` ещё местами пишет абсолютные 21, 22, 24. При обтёсывании
свести их к одному курсору.

## Стиль кода

Смотреть соседние сцены, не выдумывать обёртку.

- Класс наследует `Scene`. `DUMP_FILE` — имя json без пути.
- `action()` берёт `self.get_group(MAIN)` и больше не хранит своё время.
- Камера диалога — `LookAtCamera`. Ей нужен дамп-ключ `{name}_focus`.
  Проезд — `move_cam(index=2)` на ключ `{name}2`, фокус — `move_focus` на `{name}_focus2`.
  `cam_dbg` в сцену не переносить.
- Персонаж — `Character(..., rotate_from_quat=True)`. Имя сущности всегда
  `Char_{actor.NAME}`. Второй деформ того же актёра в THN — точка для
  `MoveFastEvent`, не второй `Character`.
- Жест — `motion` / короткий `_m`. Имя анимации брать из `Male` / `Female`,
  если константа есть. Если в THN имя, которого нет в `anim.py`, оставлять строку.
- Проп — подкласс `Prop` с `COMPOUND_TEMPLATE_NAME`, как `PDA` в `m20.py`.
  Субтитры и `offscreen` не тащить.
- IK головы — `NeckIkEvent` на `hp_neck` / `TARGET_HARDPOINT` или на маркер,
  как в исходном THN. Глаза — `EyeIkEvent`.
- Свет и `SCENE_AMBIENT` копировать из THN, не выдумывать палитру.
- Подключение к миссии — `THORN_CLASS` на классе `CutsceneProps`.
  Импорт модуля из `story.cutscenes.story_scenes`. Сценарий не менять.

## Позиции

Дамп пишет `Assets/SCENES/SCRIPTS/dumper.py`: сырой location блендера и
кватернион после `Rx(-90)`. Загрузчик в `Point` делает
`[x, z, -y]` и меняет знак xyz кватерниона.

Меш комнаты в блендере стоит в нуле и повёрнут на `Rx(+90)`, чтобы после
дампера ориентация комнаты была единичной. OBJ из `E:\FL\room` — Y-up,
как Freelancer. Импорт без перестановки осей, поворот только на объекте.

Персонаж — сам меш `trent_stand.obj`, названный как точка (`Char_trent`).
Отдельная пустышка плюс меш-ребёнок в дамп не попадают: дампер пишет каждый
объект сцены. Меш и есть точка.

Камера смотрит на свой `_focus`, чтобы в кадре было то же, что у `LOOK_AT`.
Позиции брать из `spatialprops` текстового `.thn`, не из RTC и не из
декомпила 2018 года. RTC даёт комнату, не позу.

Меш комнаты класть только если файл есть в `E:\FL\room`. Нет файла — в бленд
не подставлять чужой бар. Дамп точек всё равно нужен, меш добавляется потом
и дамп снимается заново.
