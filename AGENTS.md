# Agent notes

This mod loads from `bin\`, not from `DLLS\BIN`.

- Run `bin\freelancer.exe`. Its ini uses `path = .` and `data path = ..\data`.
- Put rebuilt `Content.dll`, `Server.dll` and `freelancer.exe` in `bin\`.
- `DLLS\BIN` and `EXE` are the retail install. Do not treat them as the running mod.
- Ini edits go in `bin\freelancer.ini`, not `EXE\freelancer.ini`.
